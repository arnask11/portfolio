AI Powered Enterprise Video Creator

Outreach MCP Server

GitHub

A functioning Model Context Protocol server built with the Python MCP SDK and FastMCP. It exposes three tools that let an MCP client like Claude interact with outreach workflows programmatically. The protocol layer, tool schemas, request handling, and server architecture were designed and implemented end to end rather than wrapping someone else’s server.

_03

Autonomous Cold Outreach Agent

GitHub

An end-to-end autonomous agent for the full outreach lifecycle: finding targets, drafting personalized messages, and sending them with no manual intervention per contact. Built on the Gmail API, OAuth2 for secure Gmail auth, and the Anthropic API with Claude Haiku for message generation and per-target reasoning.

The standout piece is deduplication via a memory.md file that persists state across runs, so the agent never emails the same professor or founder twice across sessions. That focus on statefulness and idempotency is what separates toy demos from something that can run unattended. Submitted as the coding agent showcase for YC Startup School 2026.

_04

LLM Tool Calling Failure Benchmark

A structured open-source benchmark for how and why LLMs fail at tool calling, tested across Claude Haiku, Claude Sonnet, Claude Opus, and GPT-4o mini. It runs over 200+ distinct tasks so patterns surface instead of one-off anecdotes.

Two layers go beyond a basic eval script: a self-correction path that lets the model try to recover from a failed tool call (measuring recoverability, not just failure rate), and a failure taxonomy covering malformed arguments, wrong tool selection, hallucinated parameters, and more. Built for AI security and ML systems work where evaluation rigor matters.

_06

ClaimsAI Decision Engine

GitHub

A benchmarking system for AI-driven insurance claims triage: five competing routing architectures, from a hand-written rules engine to a tool-using orchestrator agent, evaluated head-to-head on 10,000 synthetic claims. Every system is scored on accuracy and a modeled dollar-loss-per-claim rather than accuracy alone, since a bad claims decision costs money and SLA breaches, not just a wrong label.

The winning agent chains six tools — policy retrieval, fraud scoring, severity assessment, field extraction, info requests, and human escalation — and deliberately withholds policy IDs from the tree model so coverage facts come from real lookups instead of memorization. XGBoost and isotonic-calibrated fraud scoring feed the router, and routing decisions run through a SimPy queue simulation, where a skill-based assignment policy cut SLA violations 50.6% versus FIFO. Final result: 89.9% routing accuracy at $262 modeled loss per claim, versus 55.1% and $1,205 for the rules baseline.
